## 2. 输入合同（只读，见 `common/q6_case_cache.py`）

| 键 | 用法 |
|---|---|

| `frequencies_hz` (F,) | 带内 17 点原始序；逐点构流形，不作等间隔假设 |
| `pairs / tx_positions / rx_positions` | 计算绝对虚拟坐标 v_ch = tx + rx；要求 v_x 等间距且 v_y/v_z 全同（否则 not_applicable） |
| `config.propagation_speed_m_s` | 传播速度（缺省用 `epsilon_r_background` 推）；本批 = 光速 |
| `config.system_delay_si` | 硬件时延；进入**绝对到达时延**（本批 0.0） |
| `search.one_dimensional_budget` | `round_trip_tau_span_s`（传播时间 2r/v，缺省回退 `config.distance_ring_m`）、`suggested_one_d_tau_step_s`（≈3.17 ps → 距离步 ≈0.475 mm） |
| `model.response_assumption` | `S = 1` 是**共同纯相位假设**（不是已知真实发射谱）；`vector` 非空时按声明的非平坦 S 使用 |
| `k` | known-K 口径的源数（来自 case 元数据，不是评测真值读取） |

自适应口径：

* **只实现原生平面波适配**：a[f,ch] = S_f · exp(-j2πf τ) · exp(+j2πf v_x,ch sinθ / v_prop)，τ = 2r/v_prop；
  即 τ_ch ≈ (2r − v_x,ch sinθ)/v_prop，r 为**原点**双程等价距离。
  **不实现也不冒充** two_way_exact / r_ref 的"假 exact"变体：请求该 manifold 一律 not_applicable。
* **绝对时延域（A8）**：`round_trip_tau_span_s` 与 `distance_ring_m` 只给传播时间 2r/v_prop，
  搜一维时统一加上 `system_delay_si` 后再与公式里的绝对 τ 对齐（B1 输出 r̂ = v(τ̂−sys)/2；B2 把 sys 放在距离导向相位里，
  r̂ = d̂ 直接是原点距离）。否则非零 system_delay 会把可搜域相对距离环整体平移。
* **共同域**：**严格** Cartesian 边界（DOMAIN_EPS = 1e-9 仅作数值容差，**不做半格外延**）+ y<0 + r>0 + 距离环；
  域外候选不静默丢弃，逐条记进 `dropped_paths / dropped_beams`（含坐标与原因）。
  网格**边界上**的合法峰由含端点取峰器保留（`_peaks_incl_edges`：端点/平台中点均为合法峰）。

## 3. B1 = Deng, Li, Tang & Zhang 2023（Sensors 23(14):6363）§4.1

| 原文 | 本实现 |
|---|---|
| 式(8) Z = A(τ,θ)B + V；a = C(θ)[S e_τ] | `_angle_manifold`（(F*C)×F，行 (f,c)、列 f）+ 式(28) 的完整 a(τ,θ) |
| 式(9) R = Z Z^H / K（K = 频域快照数 = 本数据慢时间帧数 L） | `_covariance_noise_subspace`：`R = X^T X*/L`，eigh → U_N（(F*C)×(F*C−K)）；**无 FB、无对角加载** |
| 式(19)(20) f(τ,θ) = [S e_τ]^H Q(θ)[S e_τ]，Q = C^H U_N U_N^H C（P×P） | `B = U_N^H C`，`Q = B^H B`（Hermitian 化后 eigh） |
| 式(23) e(τ) 以参考频点归一（首元素恒 1） | 参考频点 = `frequencies_hz[reference_frequency_index]`（默认 0） |
| 式(24)—(27) 约束 e1^H e(τ)=1 → **先 DOA** θ̂ = argmax e1^H Q(θ)^{-1} e1 | `angle_stage_spectrum`：obj(θ) = Σ_i \|v_i[0]\|² / max(w_i, q_reg_rel·w_max) |
| 式(28) **后条件 TOA** P1D(τ) = 1/(a(τ,θ̂)^H U_N U_N^H a(τ,θ̂)) | `conditional_toa_spectrum`：1/‖U_N^H a(τ,θ̂)‖² |

**顺序逐字保留：先角度 → 固定 θ̂ → 条件一维时延。** 不做二维联合搜索、不引入配对阶段，
不是 B0（同模型 2D 等价性对照），也不是 separated-1D-MUSIC。

Q(θ) 的奇异性与数值正则（取代旧稿"删除奇异角候选"）：

* Q ∈ C^{P×P}（P = 17），rank Q = rank(U_N^H C(θ)) ≤ min(P, F·C − K)。本机 F·C = 17·C ≥ 34、K ≤ 3，
  故 **Q 通常可逆**；只有真方向（无噪理想情形）才退化：C(θ_l)(S∘e_{τ_l}) 落在信号子空间
  ⇒ Q(θ_l) 奇异。**接近奇异的 θ 恰是真峰所在，一律不得丢弃**。
* 固定**相对**正则：obj(θ) = Σ_i \|v_i[0]\|² / max(w_i, q_reg_rel·w_max)，q_reg_rel = 1e-12（冻结）。
  理想极限 ε→0 时该式在真方向发散；固定 floor 只把发散截成有限值。
  **不声称固定 floor 下峰位一概不变**：floor 取自 Q 自身尺度，若整段谱都偏小则可能展宽或微移峰位，
  该性质只按 §7 的实测覆盖范围申报。
  与"把 pinv 当逆"不同：pinv 会把零奇异方向整段丢掉（贡献置 0），本实现把该方向保留为
  1/(q_reg_rel·w_max)（最大项），真峰不被抹掉。仅当 Q 恰为零矩阵（w_max = 0）时报告固定饱和值 OBJ_SAT。

## 4. B1 与原文的偏离（必须随结果引用）

1. **观测几何**：原文是"发射 → 多径 → 单阵列接收"单向信道；本数据是 Tx → 目标 → Rx 被动双程 CIR。
   故 τ 是双程路径/v，r̂ = v(τ̂ − system_delay)/2 是原点双程等价距离；通道相位取**绝对虚拟坐标** v_x,ch。
2. **符号**：原文式(7) 印刷 e^{−jωd sinθ/c}；本坐标（θ = atan2(x,−y)，视轴 −Y）由解析例给出
   **相对**相位 +2πf (v_x,ch − v_x,ref) sinθ/v_prop（反号）。按本坐标实现，不照抄符号。
3. **ULA 结构**：由 case 的 pairs/tx/rx 计算 v_ch，要求 v_x 等间距、v_y/v_z 全同，否则 not_applicable
   （写明物理原因，不做变体替换）。
4. **S 未知**：S ≡ 1 是共同纯相位假设。角阶段式(19)—(27) 与 S 无关；式(28) 的 TOA 阶段含 S。
   非平坦 S 可经 `case.model.response_assumption.vector` 或 `params["s_response"]` 声明。
   **S 参考分量为 0 时显式失败**：式(23) 用 e1^H e(τ)=1 归一，参考分量为零会使约束失效；
   此时报 failed 并提示可用的非零参考索引（`params["reference_frequency_index"]`，只改参考位置、
   不改 X 列序，因此不引入数据置换/bare J）。S 全零同样显式失败。
5. **频点顺序**：不排序，按原始序逐点构流形。已用"排序 + 一致置换 + 同步改参考索引"验证与原始序结果一致（位置差 0.0 m）。
6. **协方差**：原文式(9) 无 FB、无对角加载；`case.config.is_forward_backward` 属主方法选择，
   本模块不继承，只在 diagnostics 记录并标 `forward_backward_used = False`。

## 6. B2 = Kakouche, Maali, El Korso, Mesloub & Azzaz 2021（Electronics 10(22):2805）

**公式号按原文准确标注（主审 2026-09-24 更正）**：

| 原文 | 本实现 |
|---|---|
| 式(12)(13) 逐频点阵列模型 X(t,ω) = A(θ,ω)S + N | `angle_steering`：g_c(θ,f) = exp(+j2πf v_x,ch sinθ / v_prop)（(C,F)） |
| 式(14) R̂(ω_k) = (1/N)Σ_t X X^H | `per_frequency_covariances`：逐频点 C×C，`R_f = Xf^T Xf*/L`，N = 慢时间帧数 L |
| 式(15) R̂_n = Q_n Q_n^H | `noise_subspaces`：逐频点 eigh → 噪声基 B_k（维 C−K） |
| 式(16) P_IMUSIC(θ) = Σ_k 1/(a^H R̂_n a) | `imusic_spectrum`：**直接求和**，不逐频自归一/平均/连乘 |
| 式(17)(18)(19) LCMV：min w^H R w s.t. w^H C = f，w = R^{−1}C(C^H R^{−1}C)^{−1}f | `lcmv_weights`（solve 路线，无隐式正则）；C 含全部 K 个估计角，f = e_l |
| 式(20)(21) Ŝ_l(t,ω_k) = w_k^H X | `beam_output`：`Xf @ conj(w)`，逐频点 (L,) 波束输出 |
| 式(22) Ŝ_l(t) = a(d_l0)s_l(t) + e_l，a(d) = [e^{−j2ω_k d/c}] | 跨频协方差 R_range = (S_out^T S_out*)/L（F×F） |
| **式(22) 之后的正文**（无独立公式号）：对式(22) 模型用 MUSIC，**源数固定为 1**，对每个 l 重复 | `range_music_spectrum`：噪声子空间维 F−1，导向 a(d) = S ⊙ exp(−j2πf_k(2d/v_prop + sys_delay))，峰值 d̂ = 原点距离 |
| 式(23) ŝ_l(t) = a^H(d̂_l0) Ŝ_l(t)：**波束聚焦提取呼吸波形**（不是测距谱） | **不实现**；式(24)(25) 的呼吸率同理。Q6 评测量是位置，本模块只用式(22) 后正文的距离 MUSIC |

**级联顺序逐字保留**：IMUSIC 角谱 → LCMV 波束分离 → 每个波束源数 1 的距离 MUSIC。

**共轭/相位约定（核心，主审静态发现后已修并加独立断言）**：

* 两个谱的谱值都是 a^H P_n a 形式，必须写成 **B^H a**（即 `A @ B.conj()`；角阶段 `B.conj().T @ g`）。
  复基下 `B^T a ≠ B^H a`：实测错误写法会把时延轴镜像——正确约定距离峰 1.4000 m，
  错误约定（`A @ B`）峰在 3.3965 m，谱相对差 2.7e6（见 tests 的双约定对照用例）。
* 角阶段另有一个代数等价写法 `B^T conj(g) = conj(B^H g)`（取模方后相同，实测差 2.1e-16）；
  本实现统一采用 `B^H(·)` 形式以避免歧义。

## 7. B2 与原文的偏离

1. **观测几何**：原文是单站 P440 + 射频开关切换天线的 SIMO 雷达（τ_lm = 2d/c + (m−1)d sinθ/c）；
   本数据是被动双程 CIR，阵元为绝对虚拟坐标 v_ch。角导向只用角度相位（公共距离相位被逐频点源项吸收；
   绝对 v_x 写法与"相对参考通道"写法只差模为 1 的公共标量，式(16) 谱值不变，测试记录差 2.1e-16）。
2. **符号**：原文式(12) 印刷 e^{jβ sinθ}（β = −ωd/c）；本坐标解析例给出 +2πf v_x,ch sinθ/v_prop（反号），
   按本坐标实现。
3. **距离参考**：a(d) 以**原点**双程距离为参考（τ_abs = 2d/v_prop + system_delay），
   **不做第二次参考偏移**；无噪解析例（θ=30°、r=2.0 m）实测偏差 0.0 mm（若存在伪二次偏移应为 9.5 mm）。
4. **S**：默认 S ≡ 1（共同纯相位假设），此时与原文式(22) 的纯相位导向完全一致；
   给出非平坦 S 时按"源项含 P(ω)"的原生分解把 S 并入距离导向，并在 diagnostics 标为声明式适配。S 全零显式失败。
5. **LCMV 的 R^{−1}**：不做隐式正则化。逐 (波束, 频点) 记录条件数，cond > 1e12 或求解失败 → 该波束
   记失败并计数；全部波束失败 → status = failed。可变加载仅作为**额外**固定项经 `lcmv_loading` 显式启用。
6. **频点顺序**：不排序；已用"排序 + 一致置换"验证结果一致（位置差 0.0 m）。
7. **协方差/快照**：原文式(14) 无 FB、无对角加载；本模块默认同原文，L 作为式(14) 的 N。

## 9. 已知局限（保留真实结果，不调参掩盖）

1. **B1 近等时延 / 重复目标**：两个同角度、相距 5 mm 的目标不会被人为拆开——实测 n_pred = 2，
   其中一个角度峰落在 −63.77°（旁峰），r̂ 均 ≈ 2.005 m；完全重复目标只给 1 个候选。
   K 由 case 声明，角度峰不足 K 时只报可用峰（`n_angle_peaks_found` 申报）。这是方法分辨能力，
   不是实现 bug；验收不设精度门槛。
2. **B2 同角度不同距离**：式(16) 角谱在角度域重合时无法分辨（实测 n_beams_requested=2、可用 2，
   但两个波束的距离峰落在 d̂ = 4.77 m（θ̂ ≈ 0.03°）与 4.66 m（θ̂ ≈ 67.3°），
   分别因 y/x 越界被如实记为 dropped_beams），即 LCMV 约束列近共线导致波束分离失败；
   结果**如实返回**（status ok、0 候选 + dropped 明细），不做人工拆分。
3. **B2 无噪（逐频点 R 秩 K）**：式(19) 的 R^{−1} 不可用，按原法口径显式 failed；
   `params["lcmv_loading"]`（额外固定加载）可显式启用，diagnostics 标"额外，非原法"。
   真实硬件窗因噪声使 R 满秩，不受影响。
4. **B2 距离峰与角网格分辨率耦合**：0.05° 角网格 + 1e-3 噪声下 6.5 mm 偏差，
   角网格细化到 0.005° 后为 0.0 mm（机制是 LCMV 约束在 θ̂ 处的频变复增益，不是参考偏移）。
   默认 0.05° 是冻结值，不按结果调整。
5. **B1 近奇异标志的量化依赖**：`q_singular_tol_rel = 1e-8` 只在真角度落到搜索网格点时稳定触发
   （实测 3.3e-16），离网格 0.0215° 时为 1.5e-6；该标志只用于申报，不删候选、不影响结果。
